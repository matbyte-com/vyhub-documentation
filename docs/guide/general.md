# General Settings

The `General` settings hold the basic configuration of your VyHub instance, such as the community name, the language and
which features are shown to your users.

## General Configuration

| Attribute | Description |
|-----------|-------------|
| Community Name | The name of your community. Shown in the header and used across the instance. (required) |
| Enable Shop Only Mode (Simple) | Hides or disables all features that are not shop related. Useful if you only want to use the shop. |
| Enable Landingpage | Shows a landing page as the start page of your instance. |
| Enable Ticket System | Enables the ticket system in the navigation. |
| Enable Forum | Enables the [forum](forum.md) in the navigation. Requires the Forum add-on. |
| Enable Team Page | Shows the team page that lists your staff members. |
| Enable FAQ Page | Shows the FAQ page. |
| Language | The default language of your instance (required). Missing translations can be contributed [here](https://github.com/matbyte-com/vyhub-lang). |
| Enable tutorial (first-steps) | Shows the first steps tutorial in the bottom right corner. Visible to admins only. |
| Google Analytics Tag | Optional Google Analytics tag (e.g. `UA-00000000-0`) for your Google Analytics use. Only shown when advanced settings are enabled. |

## Branding and Meta Tags

These settings control how your instance appears in the browser and when shared as a link (SEO / social previews).

| Attribute | Description |
|-----------|-------------|
| Title | The title shown in the browser tab and in link previews. Displayed in search engine results and when sharing on social media. |
| Community Description | A short description of your community. Displayed in search engine results and when sharing on social media. |
| Favicon | The icon shown in the browser tab. Uploaded as an image. |
| Preview Image URL | The image shown when your instance is shared as a link. Uploaded as an image. |
